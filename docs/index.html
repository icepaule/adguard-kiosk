AdGuard Kiosk & Captive Portal

DNS-Werbe-/Malware-Filter auf einem Raspberry Pi 3B mit Touchscreen-Statusdisplay, Bedrohungs-Watchdog und zeitlich begrenztem Domain-Unlock-Portal.

Raspberry Pi 3B · Python · AdGuard Home
Überblick Architektur Tech-Stack Quickstart

Überblick

Dieses Projekt betreibt AdGuard Home als DNS-Filter auf einem Raspberry Pi 3B und ergänzt es um ein kleines Ökosystem aus Python-Diensten: ein Touchscreen-Kiosk-Display zeigt Status und Alarme direkt am Gerät, ein Watchdog überwacht das Query-Log auf Treffer kritischer Bedrohungslisten und meldet sie per Push-Nachricht, und ein separates Web-Portal erlaubt es, einzelne Domains passwortgeschützt für 24 Stunden freizuschalten, statt den Filter dauerhaft abzuschalten.

DNS-Filterung

AdGuard Home blockt Werbung, Tracker und bekannte Malware-/Phishing-Domains zentral für alle Geräte im Netzwerk.

Kiosk-Display

Ein Touchscreen am Pi zeigt Live-Status (DHCP-Clients, Filter-Status) und wechselt bei kritischen Treffern automatisch auf einen roten Alarmbildschirm.

Bedrohungs-Watchdog

Ein Hintergrunddienst prüft laufend das AdGuard-Query-Log auf Treffer definierter kritischer Filterlisten (z. B. Threat-Feeds, Phishing) und löst bei Fund einen Alarm samt Push-Benachrichtigung aus.

Temporäres Unlock-Portal

Ein passwortgeschütztes Web-Formular erlaubt es, eine geblockte Domain gezielt für 24 Stunden freizuschalten; danach entfernt ein Timer die Ausnahmeregel automatisch wieder.

AdGuard Home ist die zentrale DNS-Filter-Instanz auf dem Pi. Der Watchdog beobachtet das Query-Log im Hintergrund und schlägt bei Treffern auf sicherheitskritischen Filterlisten (Threat-/Phishing-Feeds) sowohl lokal am Display als auch per Push-Nachricht Alarm. Über das separate Unlock-Webportal kann eine einzelne Domain gezielt und zeitlich begrenzt freigeschaltet werden, statt den Filter komplett zu deaktivieren – nach 24 Stunden wird die Ausnahme automatisch wieder entfernt. Ein Kiosk-Bedienpanel am Touchscreen erlaubt zusätzlich Neustart und Status-Abfragen direkt am Gerät.

Quickstart

Grober Ablauf zur Einrichtung auf einem frisch aufgesetzten Raspberry Pi (Details siehe README):

git clone https://github.com/icepaule/adguard-kiosk.git
cd adguard-kiosk
cp .env.example .env
# .env mit eigenen Zugangsdaten und Netzwerkwerten befüllen

chmod +x setup.sh
./setup.sh

# Kiosk-Oberfläche manuell starten (sonst per systemd-Service):
./kiosk.sh

Das Setup-Skript installiert die benötigten Pakete (X11, matchbox-window-manager, Pygame, Flask, u. a.), richtet Logrotate zur Schonung der SD-Karte ein und legt systemd-Services für das Kiosk-/Watchdog-Display sowie das Unlock-Webportal an.
